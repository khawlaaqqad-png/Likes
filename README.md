# Likes Project

A simple interactive webpage that demonstrates JavaScript event handling with multiple like buttons.

## Project Parts

### Part 1 – Single Post
- One post with a like button
- Clicking "Like" increases the like count by 1
- Built with HTML, CSS, and JavaScript

### Part 2 – Multiple Posts (Network Feed)
- Page layout with:
  - Header: "Network"
  - Left column: Profile card (avatar, "Add an avatar" link, "James Doe")
  - Right column: "Your Feed" title + three posts
- Three posts by:
  - Neil M
  - Nichole K
  - Jim R
- Each post has:
  - User name
  - Like count (starts at 0)
  - Like button
  - Post text
- Each like button increases ONLY its own post's like count

## Technologies Used
- HTML5
- CSS3 (Flexbox for layout)
- JavaScript (DOM manipulation, events)

## Key JavaScript Functions

| Function | Description |
|----------|-------------|
| `Like(button, className)` | Increases the like count for the specific post using the given class name |
